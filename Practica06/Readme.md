# Practica06

## Contenido

En la carpeta *Practica06*. podran revisar cada uno de los directorios creados para guardar dinstintos tipos de archivos.
Dentro del directorio *src*, podrán acceder a todos los codigo fuentes de las actividades realizadas, *PiInteractivo.java* 
*BinarioInteractivo.java* y *CabanaDelMisterio.java*.

Para compilar cualquier codigo fuente de la carpeta *src*, basta con ejecutar javac -d bin src/\*NombreDelArchivojava, hecho que guardara
cualquier *.class* creado en el directorio bin. 

En la carpeta *bin*, estará todo los *.class* que no es más que el *bytecode* que el JVM de Java traducirá para ejecutar lo compilado
de cada archivo *.java* en la carpeta *src*.

Para ejecutar el *.class* desde la carpeta *Practica06*, basta con ejecutar *java -cp bin NombreDelArchivo*


## PiInteractivo

El usuario ingresa un dato como *10000* y el programa calcula Pi, tirando 10000 dardos en un tablero con medio circulo, devolviendo:

Dardos Lanzados: 10000

Dardos que cayeron dentro del circulo: 7861

Estimacion de Pi: 3.144400

Por poner un ejemplo

## BinarioInteractivo

El usuario ingresa un numero entero y el programa le devuelve su binario, por ejemplo si el usuario ingresa *2*, el programa devuelve:

Numero Binario: 10

## CabanaDelMIsterio

El usuario ingresa datos, como nombre de un cliente, el prestamo que pide, los meses en que lo va pagar, la tasa de interes anual y si es un cliente responsable, si no lo es, o ninguno de esos estados. El programa te da a elegir algunas opciones y dependiendo de eso te imprime algun resultado, como el interes simple, el compuesto, una comparacion o incluso puedes elegir salir del programa
